# WebDataEditer4Go 仕様書: 機能一覧・UI挙動

本仕様書は、SRAUFactory/web-data-editor の現行機能およびUI挙動に基づき、WebDataEditer4Goにおける再実装仕様を定義するものです。

---

## 1. アプリケーション概要

WebDataEditer4Go は、ブラウザ内で完結してCSV/TSV/JSON/Markdownデータの表示・編集・相互変換を行うシングルページアプリケーション(SPA)です。
すべてのデータ処理ロジックはブラウザ上で動作する Go WebAssembly (WASM) により行われ、UI は外部ライブラリ非依存の素の HTML / CSS / JavaScript で構築されます。

---

## 2. 画面レイアウト構成

1. **ヘッダー領域**:
   - アプリケーションタイトル
   - メニューボタン群:
     - `新規作成` (モーダル/フォームトグル)
     - `ファイル読み込み` (モーダル/フォームトグル)
     - `マニュアル` (マニュアル表示トグル)
     - `クリア` (全データ消去確認ダイアログ)
     - `保存` (モーダル/フォームトグル、テーブルデータが存在する時のみ活性)
2. **操作フォーム領域 (ヘッダー直下 / アコーディオンまたはモーダル)**:
   - 選択されたメニューに応じた入力・設定コントロール群を表示
3. **メイン表示領域**:
   - 通常時: データテーブル (行・列ヘッダー、セル入力フィールド、行・列操作ボタン)
   - マニュアル選択時: 組み込みマニュアル (MarkdownをHTMLに事前レンダリングしたもの)
   - データ未作成・クリア時: 初期メッセージ・新規作成またはファイル読み込みを促す案内

---

## 3. 機能一覧とUI挙動

### 3.1. 新規作成 (New Table)
- **入力項目**:
  - 行数 (1〜50、デフォルト: 3)
  - 列数 (1〜50、デフォルト: 3)
- **挙動**:
  - `新規作成` ボタン押下時、指定された行数×列数の空セル (`""`) からなる二次元配列テーブルを生成し、画面に描画する。
  - 作成完了後、入力フォームを閉じる。

### 3.2. ファイル読み込み (Load File)
- **入力項目**:
  - ファイル形式: `CSV` / `TSV` / `JSON` (デフォルト: CSV)
  - 改行コード: `LF` / `CRLF` / `CR` (デフォルト: LF、JSON選択時は非活性)
  - ファイル選択: `<input type="file" accept=".csv,.tsv,.json">`
- **挙動**:
  - 選択されたファイルの内容をテキストとして読み込む。
  - Go WASM 側のパーサーを呼び出し、二次元配列データへ変換する。
    - **CSV**: RFC 4180準拠。ダブルクォートによるエスケープ、セル内改行を適切に解釈する。
    - **TSV**: タブ区切りとして解釈する。
    - **JSON**: 二次元配列形式 `[["a", "b"], ...]`、またはオブジェクト配列形式 `[{"col1": "a", "col2": "b"}, ...]` (1件目のキー順序を行ヘッダー扱いまたは同一キーマッピング) をパースする。
  - 読み込み成功時、テーブル領域にデータを反映し、フォームを閉じる。
  - パースエラーまたはファイル未選択時は、アラート等でエラーメッセージを表示し、現在のテーブル状態を維持する。

### 3.3. データ編集 (Table Edit)
- **セル直接編集**:
  - 各セルはテキスト入力フィールド (`<input type="text">`) であり、入力内容をリアルタイムまたはフォーカスアウト時にデータモデルへ反映する。
- **列操作 (各列ヘッダーに配置)**:
  - `＋ (前挿入)`: 1列目のみ、左端に新規列を挿入する。
  - `＋ (後挿入)`: 対象列の直後 (右側) に空の列を挿入する。
  - `- (列削除)`: 対象列を削除する。ただし、テーブルの列数が1列以下の場合は削除不可 (最低1列は保持)。
  - `N (列採番)`: 対象列の全セルに、上から順に `1, 2, 3, ...` と連番を代入する。
  - `C (列コピー)`: 対象列の直後 (右側) に、対象列と同じ内容の列を複製・挿入する。
- **行操作 (各行末尾に配置)**:
  - `＋ (前挿入)`: 1行目のみ、上端に新規行を挿入する。
  - `＋ (後挿入)`: 対象行の直後 (下側) に空の行を挿入する。
  - `- (行削除)`: 対象行を削除する。ただし、テーブルの行数が1行以下の場合は削除不可 (最低1行は保持)。
  - `N (行採番)`: 対象行の全セルに、左から順に `1, 2, 3, ...` と連番を代入する。
  - `C (行コピー)`: 対象行の直後 (下側) に、対象行と同じ内容の行を複製・挿入する。

### 3.4. ファイル保存・ダウンロード (Save File)
- **入力項目**:
  - ファイル形式: `CSV` / `TSV` / `JSON` / `Markdown` (デフォルト: 直前読み込み形式またはCSV)
  - 改行コード: `LF` / `CRLF` / `CR` (デフォルト: LF、JSON選択時は非活性)
- **挙動**:
  - 現在のテーブルデータを Go WASM 側のシリアライザーに渡し、指定フォーマットの文字列を生成する。
    - **CSV**: 必要に応じてセルをダブルクォートでエスケープ (`"` は `""` に置換、カンマ・改行を含む場合引用符で囲む)。
    - **TSV**: タブ区切りで各セルを結合。
    - **JSON**: 二次元文字配列として JSON 配列シリアライズ (`JSON.stringify`)。
    - **Markdown**: 1行目をヘッダー行、2行目をデリミタ行 (`| --- | ... |`)、以降をデータ行としてフォーマット出力。セル内の `|` は `\|` にエスケープ、セル内改行は空白文字に置換。
  - ブラウザのダウンロード機能 (File System Access API の `showSaveFilePicker` または Blob URL によるアンカークリック) を用いて、`web-data-editor.{ext}` として保存・ダウンロードを実行する。
  - Markdown形式選択時は、画面上に `クリップボードにコピー` ボタンも表示し、ワンクリックで Markdown テーブル文字列をクリップボードに格納できる。

### 3.5. データクリア (Clear Data)
- **挙動**:
  - `クリア` ボタン押下時、ブラウザ確認ダイアログ (`confirm`) を表示する。
  - ユーザーが承認した場合、テーブルデータ配列を空 (`[]`) に初期化し、テーブル表示をクリアする。

### 3.6. マニュアル表示 (Manual Viewer)
- **挙動**:
  - `マニュアル` ボタン押下時、テーブル表示領域をマニュアルコンテンツに切り替える (トグル切り替え可能)。
  - ビルド時に Markdown から事前生成された HTML 静的コンテンツを直接表示する。
